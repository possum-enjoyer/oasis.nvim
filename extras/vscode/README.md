# Vscode Setup

1. Clone the Repo
2. Navigate to extras/vscode
3. Build the Vscode theme [by using the vsce package command](https://code.visualstudio.com/api/working-with-extensions/publishing-extension#packaging-extensions)
3. Install the generated .vsix file, either using the commandline: ```code --install-extension \<insert ExtensionName here\> ``` or by clicking on the 3 dots in the Extensions Tab and select "Install from VSIX..."
